## Writing a new post

Create a file in `_posts/` named `YYYY-MM-DD-some-title.md` with this header:

```yaml
---
layout: post
title: "My Post Title"
description: "One-line summary shown on the blog index."
tags: [research, tutorial]
---
```

Then write in Markdown. You get **bold**, *italics*, [links](https://example.org),
code blocks, tables, and images:

```python
def hello():
    print("Hello from a code block")
```

> Blockquotes work too.

Push to GitHub and the post appears on the site within a minute or two.
